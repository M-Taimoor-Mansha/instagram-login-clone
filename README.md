# Instagram Login Page Clone 📸

A pixel-perfect, responsive UI clone of the official Instagram login interface, built using **HTML5**, **CSS3**, and **JavaScript** for layout practice and interactive web design fundamentals.

---

## 🌟 Features

* **Pixel-Perfect UI:** Recreates the original Instagram login page layout and branding.
* **Interactive Elements:** Uses JavaScript for basic form interactivity and input handling.
* **Fully Responsive:** Adapts cleanly across mobile, tablet, and desktop viewports.
* **Flexbox Layout:** Utilizes modern CSS layout techniques for clean alignment and positioning.
* **Clean Code Structure:** Well-organized semantic HTML, styled CSS, and lightweight JS logic.

---

## 🛠️ Tech Stack

* **HTML5:** Semantic markup structure
* **CSS3:** Custom styles, Flexbox, layout positioning, and media queries
* **JavaScript:** Frontend interactivity and DOM manipulation
